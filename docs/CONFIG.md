# Настройки SDCoop

Все настройки лежат в `SurrounDead\Binaries\Win64\ue4ss\Mods\SDCoop\config.ini` (строки `ключ = значение`).
Файл создаётся при первом запуске; часть настроек меняется в игре (главное меню → «Кооператив» или панель F7).
Править руками — только при закрытой игре. Ключи, которых нет в файле, берут значение по умолчанию.

Таблица собрана из `SCHEMA` в `mods/SDCoop/scripts/sdc_config.lua` (там же порядок записи в файл).

| Ключ | Тип | По умолчанию | Что делает |
|---|---|---|---|
| `host_ip` | string | `(пусто)` | Код друга (Steam) или IP хоста для подключения |
| `port` | int | `7777` | Порт хоста (UDP). Хост всегда слушает 7777 |
| `player_name` | string | `(пусто)` | Ваше имя для других игроков; пусто = имя в Steam (без Steam — имя пользователя Windows) |
| `listen_on_load` | bool | `true` | Хост: любой загруженный мир (сохранение/новая игра) сразу открыт для друзей |
| `auto_join` | bool | `false` | Клиент: подключаться к host_ip автоматически из главного меню |
| `auto_host` | bool | `false` | Тест: сразу открыть auto_host_map как сервер из главного меню |
| `auto_host_map` | string | `/Game/Levels/LongdownValley` | Карта для auto_host и команды sdcoop_server |
| `no_pause` | bool | `true` | Не ставить мир на паузу, пока подключены другие игроки |
| `sync_env` | bool | `true` | Синхронизировать время суток и погоду с хостом |
| `unload_menu_level` | bool | `true` | Клиент: выгружать свою сцену главного меню в игре (её небо и погода рисовались поверх мира хоста: вечный день, снег) |
| `block_menu_level` | bool | `true` | Клиент: не загружать свою сцену главного меню при подключении (её небо и погода рисовались поверх мира хоста; «Выйти в меню» на экране смерти отключает от хоста) |
| `respawn_native` | bool | `true` | Клиент: возрождение кнопками самой игры (её «сохранять инвентарь» по сложности, статистика смерти); выкл = кнопки мода |
| `guard_player_sweeps` | bool | `true` | Хост: экраны смерти, паузы и загрузки игры убирают только персонажа хоста, а не подключённых игроков |
| `fresh_client_progress` | bool | `true` | Клиент: если у хоста нет сохранённого персонажа этого игрока — начинать с прогрессом нового персонажа (уровень 1, без навыков и очков); выкл = не трогать |
| `persist_clients` | bool | `true` | Хост: персонажи подключавшихся игроков (инвентарь и снаряжение, уровень, навыки, здоровье, место, точка возрождения) сохраняются вместе с миром хоста (файлы <слот>_SDCoop в SaveGames) и возвращаются при повторном подключении |
| `persist_period` | int | `120` | Хост: раз в N секунд дополнительно записывать персонажей игроков на диск (страховка от вылета); 0 = только при сохранении игры, смене инвентаря, смерти и выходе игрока |
| `persist_restore_position` | bool | `true` | Хост: вернувшийся игрок появляется там, где вышел (если был жив); выкл = рядом с хостом |
| `persist_follow_host_save` | bool | `true` | Хост: персонажи друзей следуют за сохранениями мира, как персонаж одиночной игры: при загрузке сохранения (в том числе после вылета) каждый друг возвращается в то состояние, в каком был на момент этого сохранения (место, инвентарь, здоровье, уровень, навыки, открытые места на карте, точка возрождения, задания); кто появился в мире после сохранения — начинает заново. Выкл = друг продолжает с последнего состояния, даже если мир загружен из более раннего сохранения (предметы из сундуков могут задвоиться) |
| `persist_map` | bool | `true` | Хост и клиент: открытые игроком места на карте (города, локации) сохраняются вместе с его персонажем у хоста и снова открываются на карте при повторном подключении |
| `map_shared` | bool | `true` | Места на карте (города, локации), открытые любым игроком, видны на карте у всех — у хоста и у каждого клиента, сразу и после подключения. Чужое место только показывается, бледной меткой («видел другой игрок»): когда игрок сам дойдёт туда, метка становится обычной, и он получает опыт и сообщение об открытии. Решает хост; выкл = каждый видит только свои места (у клиента выключение только не показывает чужие места на его карте) |
| `persist_player_id` | string | `(пусто)` | Клиент: постоянный номер игрока для сохранений у хоста, если игра запущена без Steam (создаётся сам; не менять — иначе хост не узнает персонажа) |
| `skilltree_sync` | bool | `true` | Хост: навыки из дерева навыков клиента (реген здоровья, второй шанс, крит. удар, ночной бонус) действуют и в расчётах хоста |
| `bed_for_client` | bool | `true` | Хост: кровать и спальник игрока — окно сна, «рано спать» и точка возрождения у этого игрока, а не у хоста |
| `client_sleep_skips_night` | bool | `true` | Хост: сон игрока в кровати пропускает ночь для всех, как сон хоста |
| `coop_sleep_all` | bool | `true` | Кооператив: ночь пропускается, только когда спят все подключённые игроки (каждый ложится в кровать или спальник и нажимает «Спать»); уснувший ждёт остальных с надписью «Ждём, пока уснут все игроки (1/2)», Esc — встать. Выкл = как раньше: сон любого игрока пропускает ночь для всех |
| `unstuck_cooldown` | int | `30` | Клиент: как часто можно нажимать «Застрял? К хосту» (секунды) |
| `ai_fix` | bool | `true` | Зомби только серверные: реплицировать их с хоста и убирать локальные копии у клиента |
| `respawn_delay` | int | `30` | Через сколько секунд без персонажа хост сам создаёт его игроку |
| `char_create` | bool | `true` | Свой персонаж для кооператива: создаётся в редакторе игры в главном меню перед первым подключением (Mods/SDCoop/character.txt); хост создаёт персонажа с этой внешностью |
| `fix_capsule_replication` | bool | `true` | Хост: капсула персонажей игроков не реплицируется (иначе позиция сервера может откидывать персонажа клиента назад) |
| `ai_kill_credit` | bool | `true` | Зомби, боссы, люди и животные, убитые клиентом: убийство, опыт, очко навыка и сообщение получает клиент, а не хост |
| `ai_attack_montages` | bool | `true` | Клиент видит атаки зомби, боссов, волков и медведей, реакцию на попадания, отталкивание и крик |
| `ai_corpses` | bool | `true` | Трупы зомби, боссов и животных остаются у клиентов: лежат, их можно обыскать или разделать |
| `ai_healthbar` | bool | `true` | Полоса здоровья врага у клиента показывает здоровье с хоста и возвращается после смерти и возрождения |

| `ai_zombie_looks` | bool | `true` | Зомби у клиента такие же, как у хоста: ползает или стоит (высота капсулы и модели — без висения в воздухе и провала в пол), модель, материал, скрытые кости, анимация ходьбы, имя, броня пса; клиент не выбирает тип зомби сам |
| `ai_kill_log` | bool | `true` | Писать в UE4SS.log каждое убийство зомби: тип, вид (модель, материал), ползун или нет, кто убил, урон, место; раз в минуту — счёт убийств по типам |
| `ai_client_ghosts` | bool | `true` | Клиент: свои спавнеры ИИ игры не создают зомби, боссов и животных, а уже созданные только у клиента (стоят или висят в воздухе) удаляются — все ИИ приходят от хоста |
| `ai_zombie_fx` | bool | `true` | Клиент видит и слышит эффекты особых зомби: писк и взрыв зомби-гренадёра, взрыв кислотного зомби после смерти |
| `npc_offscreen` | bool | `true` | Хост: боссы-зомби бьют и бросают камни, а люди (бандиты, солдаты, мародёры) двигаются и бьют рядом с клиентом, даже если хост на них не смотрит (иначе босс не наносил урон клиенту и застывал после броска) |
| `npc_boss_fx` | bool | `true` | Клиент видит камень, брошенный боссом, и слышит рёв босса (атака, бросок, смерть) |
| `npc_effects` | bool | `true` | Клиент видит огонь на горящих боссах и людях и кровь при попадании по ним |
| `npc_health` | bool | `true` | Полоса здоровья бандитов, солдат, мародёров и торговцев у клиента считается от максимума здоровья с хоста |
| `npc_looks` | bool | `true` | Вид людей (одежда, причёска, борода, рюкзак, шлем, маска) у клиента как у хоста |

| `player_names` | bool | `true` | Имя другого игрока над ним, когда вы смотрите на него или стоите рядом (табличка, как у мирных жителей) |
| `player_names_range` | int | `40` | С какого расстояния (м) видно имя игрока, на которого вы смотрите |

| `gps_markers` | bool | `true` | Игроки с GPS видны остальным на большой карте (точка с именем; метки на карте видны, только если GPS есть и у вас) |

Решает хост; выкл = каждый видит только свои метки (у клиента выключение только скрывает чужие метки на его карте) |
| `hide_zero_damage_numbers` | bool | `true` | Клиент: не показывать «0» при ударе ножом (локальный удар клиента без прав сервера; настоящий урон приходит от хоста) |
| `client_hitmarker` | bool | `true` | Клиент: хитмаркер у прицела при попадании из огнестрельного оружия и арбалета, как в одиночной игре (белый — в тело, красный — в голову); раньше у клиента его не было совсем |

| `mirror_sounds` | bool | `false` | Запасной путь: хост пересылает клиентам звуки предметов игроков сообщением SND |

| `perf_report` | int | `60` | Отладка: раз в N секунд писать в лог [PERF] — FPS и сколько времени игры занимают самые тяжёлые перехваты и задачи мода; 0 = выкл |
| `perf_bench_no_bp_hooks` | bool | `false` | Отладка, только одиночная игра: мод не ставит ни одного перехвата Blueprint-функций (UE4SS тогда не проверяет каждый вызов Blueprint). Для замера sdcoop_bench: прогон с этой настройкой и без неё показывает, сколько стоит проверка UE4SS. Кооператив в этом режиме НЕ работает; действует после перезапуска игры |
| `debug_net` | bool | `false` | Отладка: писать в лог каждое сетевое сообщение мода (их десятки в секунду; без этого частые сообщения не пишутся) |
| `debug_probes` | bool | `false` | Отладка: тяжёлые датчики движения (перехват функций перемещения и репликации каждый кадр) — сильно нагружают игру; только для поиска рывков движения |
